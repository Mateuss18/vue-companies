# Desenvolvedor Full Stack (Ruby + Vue) - ART IT - Intelligent Technology

Estamos em busca de um Desenvolvedor(a) Full Stack para atuar no desenvolvimento e sustentação de aplicações web, contribuindo na construção de soluções escaláveis, integrações e evolução contínua da arquitetura dos sistemas.

Responsabilidades

Desenvolver e manter aplicações web full stack (backend e frontend).
Projetar, desenvolver e consumir APIs REST.
Trabalhar com arquitetura orientada a eventos (event-driven).
Colaborar com o time na definição de soluções técnicas e melhorias arquiteturais.
Garantir qualidade de código por meio de testes, code review, boas práticas e segurança.
Participar de deploys e melhorias de infraestrutura.

Requisitos

Experiência prática com desenvolvimento web full stack.
Conhecimento sólido em Ruby on Rails.
Conhecimento desejável em PHP utilizando Laravel/Lumen.
Experiência com Vue.js no desenvolvimento frontend.
Experiência com construção e consumo de APIs REST.
Conhecimento em arquitetura orientada a eventos (event-driven).
Familiaridade com bancos relacionais como MySQL e PostgreSQL.
Experiência com Git no fluxo de desenvolvimento (branching, Pull Requests e code review).
Conhecimento básico de Docker e containers.
Conhecimento básico em GCP (Google Cloud Platform).

Diferenciais

Experiência com arquitetura de microsserviços.
Conhecimento em ferramentas de mensageria como RabbitMQ, Kafka ou Pub/Sub.
Experiência com pipelines de CI/CD.
Vivência com testes automatizados.
Conhecimento em observabilidade (logs, métricas e tracing).
Experiência na utilização de IA aplicada ao desenvolvimento de software, utilizando ferramentas como Cursor e GitHub Copilot para aumento de produtividade, refatoração, debugging e aceleração do ciclo de desenvolvimento.
